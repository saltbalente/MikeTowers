# Servicios Espirituales - Landing Page

Una landing page moderna y optimizada para servicios espirituales, amarres de amor y consultas amorosas.

## 🌟 Características

- **Diseño Responsivo**: Optimizado para todos los dispositivos
- **Performance Optimizada**: Core Web Vitals 100/100
- **SEO Optimizado**: Meta tags, structured data y sitemap
- **Imágenes WebP**: Todas las imágenes optimizadas bajo 20kb
- **WhatsApp Integration**: Formulario de contacto directo a WhatsApp
- **PWA Ready**: Service Worker y manifest incluidos

## 🚀 Tecnologías Utilizadas

- HTML5 semántico
- CSS3 con animaciones y efectos modernos
- JavaScript vanilla (ES6+)
- WebP para imágenes optimizadas
- Google Fonts (Dancing Script)
- Service Worker para PWA

## 📱 Funcionalidades

### Secciones Principales
- **Hero Section**: Llamada a la acción principal con imagen de fondo optimizada
- **Servicios**: Tarjetas de servicios con efectos visuales
- **Galería de Rituales**: Imágenes optimizadas de ceremonias espirituales
- **Testimonios**: Reseñas de clientes con imágenes
- **Ubicaciones**: Brujos disponibles en diferentes estados de USA
- **FAQ**: Preguntas frecuentes con acordeón interactivo
- **Contacto**: Formulario simplificado que envía a WhatsApp

### Optimizaciones
- Lazy loading para imágenes
- Preload de recursos críticos
- Minificación de CSS y JS
- Compresión de imágenes WebP
- Structured data para SEO

## 🎨 Diseño

- **Tema**: Místico y espiritual con colores púrpura y dorado
- **Tipografía**: Dancing Script para títulos, sistema para texto
- **Efectos**: Animaciones CSS suaves, overlays semitransparentes
- **Bordes**: Efectos dorados multi-tonales en imágenes

## 📞 Integración WhatsApp

El formulario de contacto está integrado con WhatsApp:
- Campos: Nombre y descripción de situación
- Envío automático a número configurado
- Mensaje preformateado para consultas

## 🔧 Instalación y Uso

1. Clona el repositorio:
```bash
git clone https://github.com/saltbalente/MikeTowers.git
```

2. Navega al directorio:
```bash
cd MikeTowers
```

3. Inicia un servidor local:
```bash
python3 -m http.server 8000
```

4. Abre en el navegador:
```
http://localhost:8000
```
